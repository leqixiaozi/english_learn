# english_learn

## 项目与文档范围

面向中文母语成年程序员的个人语言学习与表达网站，优先英语，第二语言为德语。围绕生活交流、商务与技术沟通、个人观点表达，帮助学习者把想法转化为能交流、能口述的视频内容。

当前方向为从基本词句起步的场景教学＋专项训练：由一个连续项目或故事串联模拟工作与生活，助手带着推进；按发生频率和实用性选择任务，不专门背词。听说读写融入各幕，中文表述到英文语法单列专项。

当前已逐项整理 365 张完整场景卡，从介绍自己与面试，到项目、沟通、出差、交付和自己的英文观点视频。每项都有触发情境、交流过程和完成结果，不能把单一称呼、句型或编辑动作拆成一场凑数。365 是覆盖数量，不是每日课表；英语课文与音频等待后续编写，已有示范只作方向草案。

外部教材与视频用于研究场景、难度和教学方法，也可作为任务输入；本人原创故事仍是学习主线。用户已确认系统私人使用、不对外开放，**每场景只嵌入 1 个主视频，其余为参考链接，下载限来源方正式提供或允许的入口**。当前视频库为候选及部分场景推荐，尚未逐场景选定或接入播放器。

当前仓库处于需求与设计阶段，尚无网站源码、运行服务或数据库。文档中的建议方案不代表已实现功能，也不构成编码、模型调用或部署授权。

## 按任务读取

| 任务 | 必要入口 |
| --- | --- |
| 理解定位、需求或确认学习方式 | 产品总览的定位、语言规则、主要流程和待确认项 |
| 查看课程顺序与贯穿故事 | 课程与练习规划 → 365 场景故事线；中文句子卡点进入独立语法专项 |
| 找教材、检查版次或核完整性 | 教材编写参考的资料入口 → 原版教材知识库／系列课程目录 → 参考原件清单 |
| 把参考资料用于原创教材 | 场景与题型参考库 → 对应场景卡；局部示范只作方法参考 |
| 选视频或继续核片段 | 视频参考库 → 视频清单中的逐场景证据；播放器设计另读架构总览 |
| 讨论页面、功能或技术方案 | 产品总览相关流程 → 架构总览 |
| 开始编码或验证 | AGENTS → 开发规范 → 建设规划中的前置条件 |
| 维护文档、提交或推送 | AGENTS 的个人流程入口 → 对应正文；提交只包含本任务改动 |

源码证明实现现状，已确认需求说明目标。出现差异先核对依据、适用范围与本次授权，不把建议写成已批准决定，也不为迎合实现擅自改动需求。
