# 架构与模块边界

范围为需求阶段的模块职责和技术决策边界。当前只有文档，没有前后端、接口、数据库、外部模型配置或运行服务；不存在可据源码描述的实际调用链和数据表。

产品规则以[产品总览](../10产品/总览.md)为准。下述模块划分是建议方案，待实施范围确认后细化。

## 1. 目标与约束

支持当前学习语言与双语显示，把场景、资料和个人输出连接起来；语言变化不能破坏作品归属，辅助内容不能覆盖用户原意。

当前学习组织已收敛为场景教学＋专项训练，英语从基本词句开始；不设独立背词模块，按真实发生频率与实用性选择少量任务。词汇和语法随任务使用，听说读写融入场景，中文到英文句子为独立核心专项。详见[课程规划](../10产品/课程与练习规划.md)。

场景由同一贯穿项目或连续故事连接，助手带着用户从头推进模拟工作和生活。当前人物、目标、约定与累计作品应跨章节沿用；不能在换一幕或打开专项后丢失项目上下文。具体对象仍为教学建议，不等于授权开发该项目的软件。

为英语优先、德语扩展留出语言边界。界面文案、学习内容、用户作品和参考链接的语言归属需要明确，不能靠改页面标题模拟多语言。

## 2. 建议模块职责

| 模块 | 负责 | 依赖 |
| --- | --- | --- |
| 语言与显示偏好 | 当前语言、双语开关和中文辅助呈现 | 语言资源 |
| 场景学习 | 连续项目中的生活、职场和技术任务，承接前一幕成果 | 项目故事与角色、语言偏好、学习内容、资料 |
| 观点表达 | 原始想法、结构整理、外语候选和用户定稿 | 语言偏好、表达材料；可选语言辅助服务 |
| 视频稿准备 | 将选定作品整理为口述稿 | 观点作品 |
| 资料与表达库 | 来源链接、可复用表达和作品检索 | 内容及作品归属 |
| 保存能力 | 保存偏好、输入和用户选择结果 | 待定存储方式 |
| 可选语言辅助 | 改写、朗读或识别等能力 | 待确认外部服务及授权 |

## 3. 依赖方向与关键机制

场景练习和观点表达共享语言偏好及表达材料。视频稿准备以用户选定的作品为输入；参考资料可以附着于任务，不能替代用户内容。

建议将展示语言与内容语言分开建模：切换显示不能篡改作品语言；原始中文想法与目标语言表达存在关联，但保持各自内容。此处描述业务概念，不指定数据库字段、表名或接口结构。

辅助生成结果建议作为候选交给用户选择。若引入 AI，需区分原稿、候选和已选内容；调用失败、超时或取消保留输入，不自动重试并覆盖正式作品。使用外部能力前明确服务对象、发送内容、费用和权限。

## 4. 数据与存储现状

尚无实际存储或 schema。本次不创建数据库、数据字典、迁移和空表设计。预期需要保存的业务对象包括语言偏好、学习材料、贯穿项目的角色与已确认事实、当前章节、原始想法、用户选定作品及参考链接；是否保存录音和练习记录仍待确认。

浏览器本地保存、文件保存或服务端持久化应依据使用设备、数据量和备份要求选择。个人使用不等于已授权公开托管，也不自动需要账号体系。

## 5. 质量目标及边界

- 切换语言与双语显示后，内容归属和用户输入保持正确。
- 错误、空内容和参考链接受限状态可理解，失败不吞掉用户稿件。
- 后续界面应支持清晰阅读、键盘操作和表单标识；设备范围及响应式验收需确认。
- 正式作品与辅助候选的区分可见；保存、录制和发布结果分别说明。
- 模型或语音能力未接入时如实呈现，不用模拟响应冒充真实能力。

没有已批准的并发规模、延迟、可用率或学习效果数值，不编造指标。

## 6. 待定技术决策

技术栈、运行时版本、页面路由、API、数据存储、账号权限、AI 服务、语音服务和部署方式均未确定。进入实施时先核现有工具和项目要求，复用环境与缓存，不为文档安装依赖或启动服务。

## 7. 开源底座选型

### 用户明确的选型要求

2026-10-17 用户要求寻找可复用的开源底座，具备代码规范，以及已经建立的界面规格；同时调查相似产品和内容。用户进一步明确需要成人使用、成体系、主要覆盖职场、技术和生活交流。具体项目、技术栈与功能复用方式尚未选定。

选型需核实际仓库中的规范配置、目录与组件约定、主题和布局规则，不能仅以截图或 README 的质量宣传作为依据。组件库的视觉规范不等于本站的完整学习交互规格；目标语言、双语显示、观点编辑和视频稿流程仍须按产品需求补齐。

## 8. 场景与中文句子专项的交互框架建议

针对最新收窄的目标，建议以 **Vue 3＋Vite＋Nuxt UI 的 Vue Dashboard 模板**作为本站前端基础，长文本编辑需要时引入 **Tiptap 3 的 Vue 适配**。优先复用组件、布局和视觉规范；场景步骤、语法提示和学习记录由本站组织。此处是推荐路线，尚未批准采用或安装，也不决定后端和部署方式。

理由是本站需要材料、作答、反馈和句子编辑共享一个任务，能按步骤切换、保留输入、按需显示辅助，而非把全部流程固定为聊天消息。Nuxt UI 模板提供可折叠侧栏、主题和键盘入口；4.x 的 DashboardPanel 源码提供可调尺寸及 header/body/footer 插槽，适合组合材料与练习。Tiptap 支持 Vue 与自定义扩展，可用于较长观点稿；句级短答优先普通输入框，不为每个空格引入富文本编辑器。语法标注、中文对照、录音和学习流程均需实现，不是这些库的现成功能。

| 学习交互 | 建议页面方式 | 需要保持的行为 |
| --- | --- | --- |
| 场景教学 | 当前故事章节和主要任务区，材料与短听读／说写步骤切换 | 上一幕成果进入下一幕；输入、人物和进度不因切换丢失 |
| 当前卡点专项 | 就近打开短练习，完成后回到场景 | 不跳入背词中心或大型语法目录 |
| 中文到英文句子 | 自己的中文、句子骨架、本人尝试和按需提示 | 提示逐级展开；完整参考句可隐藏；不逐字强行对应 |
| 双语 | 对已经展示的材料按用户偏好提供中文对照 | 不改变原稿，不强行揭示听力原文或练习答案 |
| 观点与视频稿 | 需要时进入编辑区，附口述练习 | 原稿、候选、定稿清楚；语音能力按实际接入状态展示 |

桌面可用可收起导航、主任务区及按需辅助面板；基础学习不默认塞满三栏。手机按一步一屏或抽屉呈现，输入与录音状态需保持。完整的学习交互规格仍要建设，组件库不代替产品规格。

- [官方 Vue Dashboard 模板](https://github.com/nuxt-ui-templates/dashboard-vue)：MIT；本轮读取 package，见 Vue、Vite、Nuxt UI 4.x、lint 与 typecheck，根脚本未列 test。本轮未运行它的检查，也未创建本站应用。

## 9. 私人学习的视频与参考资料边界

用户已确认仅供本人使用、不对外开放，并且每场景只嵌入 1 个最合适的主视频，其余为参考跳转。具体选编及证据维护在[视频参考库](../10产品/10学习资料/视频参考库.md)和[视频清单](../../reference-library/视频清单.json)；本节不另复制视频列表，也不建立播放器代码、数据库或接口。

YouTube 使用官方 iframe／IFrame Player API，候选地址按 [官方嵌入说明](https://support.google.com/youtube/answer/171780)构造，可采用 youtube-nocookie.com 的隐私增强域名。片段开始、结束及字幕参数以[官方参数文档](https://developers.google.com/youtube/player_parameters)为准。上传者可能关闭嵌入、视频可能受地区／年龄／登录条件限制；[官方错误说明](https://developers.google.com/youtube/iframe_api_reference#Events)还列出 153：缺少 HTTP Referer 或等效客户端识别。正式接入时须在真实服务地址验证，不能由 oEmbed 成功推断播放成功。

B 站使用[官方站外播放器文档](https://player.bilibili.com/)所列入口与 bvid、p 或 cid；默认关闭自动播放和弹幕的建议只影响后续实现。多 P 链接必须保存具体 P／cid，不能仅存合集 BV 后就声称打开了指定课程。页面可访问与站外播放器可播放分别验证。

用户全站默认目标语言、可切双语的规则继续有效。本站原创说明和对照可控制；视频烧录字幕不能承诺可关闭，平台独立字幕也不能保证都有中文或可被本站开关控制。只有实际核到的字幕语言、字幕类型才写入已验证字段。

私人用途不自动意味着所有内容都无使用限制。[著作权法官方文本第二十四条](https://wb.flk.npc.gov.cn/flfg/PDF/3d00c03d87cf4863878081a3e1b54638.pdf)涉及个人学习等使用，也列有署名和不得影响正常使用等条件；平台播放与下载方式另受其规则影响。当前采用原站链接、官方嵌入候选和来源方正式下载入口，不由此扩展为绕过会员、提取播放流或镜像整套媒体。

参考区区分“观看”“文字稿／练习”“官方视频下载”“其他原件”。当前视频候选均未核到可直接分享的官方视频文件下载 URL，清单相应字段留空；官方文字稿 PDF 或已有教材 PDF 可以作为文字资料入口，但不能显示为视频下载。未实施视频下载、收费内容取得或字幕提取。

外部视频服务于原创故事的沟通任务，观看后回到本人说写。当前没有播放器实现；网络、上传者设置、客户端识别和分 P 定位须在真实运行地址验证，失效时保留学习输入并提供原站入口。
