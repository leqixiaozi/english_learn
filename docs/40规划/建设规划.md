# 建设范围与阶段建议

当前范围为确认需求、课程规划、框架建议、教材选编、365 场景故事大纲与视频参考，暂时不写代码。需求包括基本词句起步、场景教学＋专项训练、连续项目或故事串联模拟工作与生活、场景去重、干中学且不专门背词、按发生频率和实用性收窄，并覆盖听说读写及独立中文语法专项。已确认私人使用、不对外开放，每场景只嵌入一个主视频，其他资料作为参考链接。具体提交、推送与实施操作按用户当前授权执行；不因完成文档自动安装应用、调用模型、采集个人音视频或部署。

产品目标见[产品总览](../10产品/总览.md)，技术边界见[架构总览](../20架构/总览.md)。本文件只维护建设顺序与启动条件，不记录日常进度。

## 1. 文档与资料职责

沿用项目读取入口及现有目录：产品总览维护已确认要求，课程规划维护高频场景与随用随学规则，中文语法专项维护从本人意图搭建句子的训练建议，架构总览维护框架建议和已查证据；README 提供索引。既有开源调查与公开页面截图作为选型依据保留，不把候选功能写成本站实现。

外部教材供编写者研究场景、难度与教学方法，来源和已核范围见[教材编写参考](../10产品/10学习资料/教材选编.md)及[原版教材知识库](../10产品/10学习资料/原版教材知识库.md)。本地完整原件、样章和目录记录在[原件清单](../../reference-library/清单.json)，第三方 PDF 原件目录已忽略，不把全文和媒体打包进 Git。用户后续会要求助手原创教材，当前不安排整套外部课程为主课，也不提前编写整套教材。原先的[项目局部示范草案](../10产品/10学习资料/项目故事示范课.md)仅供检查交互方向，不是最新故事线的第一幕。

[365 场景故事线](../10产品/365场景故事线.md)维护从求职到英文观点视频的完整事件卡；具体设定仍为教学草案，不等于已编成英语课文、音频或练习。[视频参考库](../10产品/10学习资料/视频参考库.md)维护来源目录及当前覆盖，[视频清单](../../reference-library/视频清单.json)维护逐场景的候选、参考、片段证据与空缺。正文适配、正式采用、音画和本站播放分别核验，播放器尚未开发。

EVOLVE／Keynote 第二版的目录、样章、完整套装线索和取得缺口，由原版教材知识库维护；实际活动机制由[场景与题型参考库](../10产品/10学习资料/场景与题型参考库.md)维护。获取线索未核实不阻止已有场景继续研究，也不能据此宣称整套教材已取得或适合基础起点。

文档应使其他开发者能够区分已明确要求和设计建议，不能把待定技术选择或用户水平写成事实。

## 2. 建议建设顺序，待确认

| 建议阶段 | 目标与交付成果 | 启动依赖 |
| --- | --- | --- |
| 英语最小闭环 | 一个高频任务贯通短听读、本人说写、卡点提示和表达保存；中文到英文句子专项可返回当前场景；不建背词中心 | 英语已确认基本词句起步；确认首批场景、使用方式及技术方案 |
| 观点与视频稿 | 中文观点组织、外语表达、用户定稿、口述稿准备相互衔接 | 最小闭环的内容和保存能力；确认视频主题与格式 |
| 德语内容扩展 | 提供适合当前水平的德语场景与表达任务，保留独立成果 | 确认德语水平及建设范围 |
| 可选 AI 与语音自动反馈 | 在已有听说活动上加入陪练、候选改写、识别或自动反馈；听说本身为已确认需求 | 用户确认具体服务、费用与数据发送边界 |

推荐先让用户完成一次有用表达，再扩大内容和辅助能力。多语言边界从设计开始保留，德语内容的上线顺序并未批准；若用户需要首版同步支持，应调整上述阶段。

视频目标先明确内容准备与实际录制的边界。自动剪辑、成片和发布不包含在上述建议阶段，不能因“视频输出”自动扩大范围。

## 3. 保持项与前置条件

实施须保持现有检出及当前分支，保护其他任务改动；先确认阶段范围，再核工具及依赖。不因生成文档而安装框架、创建数据库或调用模型。

启动编码前集中确认：首批高频场景、德语水平与首版范围、视频产物形式、AI 或语音自动反馈方式，以及使用设备、运行环境和保存方式。英语基础起步、私人使用和每场景单主视频均已确认，不重复作为未回答问题。具体未决项在产品总览维护，本处不复制答案。

## 4. 交付与进入下一阶段的依据

本次交付依据是文档覆盖用户要求、365 编号连续且无缺项、候选清单及其场景引用一致、索引与本地链接有效，且未将建议或元数据核验冒充正式采用与播放验收。它不包含任何网站运行或业务验收。仅在另获当前 Git 交付授权后，才暂存本任务文件、提交、推送并核远端目标分支；文档同步本身不触发这些操作。

后续阶段以获确认的产品目标和可观察结果为依据，按相应阶段运行实际验证。文件数量、页面外观或 HTTP 成功不能替代“用户能够完成表达任务”的业务成果。
