# 中文表述到英文语法

## 定位

这是用户明确要求的独立核心专项：用本人想说的中文，学习怎样搭建英文句子；从基本词句开始，为高频场景服务。整体范围见[产品总览](总览.md)，课程组织见[场景教学与专项训练](课程与练习规划.md)。下文为建议训练方式，不宣称已经实现或经实验证明最快。

不建立另一本从头背到尾的语法大全，不另设词汇背诵。中文用于明确意思和暴露当前结构卡点，随后逐步减少完整译文提示，最终能直接用英语回应场景。无需把每句话都先想成中文才能开口。

专项绑定贯穿项目中的真实表达意图：先确认用户在当前剧情想说什么，再教完成这句话所需的结构，随后回到同一人物、任务与项目成果。可以独立进入查看，但不随机提供与当前故事无关的中译英题库。

## 1. 一次只解决自己要表达的意思

建议流程：输入自己的中文 → 确认意思和语境 → 拆出“谁、做什么、什么时候、对谁／什么” → 自己尝试搭英文 → 按需查看最小提示和参考表达 → 解释当前用到的语法 → 改一个条件再说 → 回到实际场景。

例如“我改了接口”未说明具体时间，也未说明是在讲过去经过还是强调现在已经可用。不能仅凭“了”就机械判断时态；有影响时先问清语境，或分别说明两个表达的适用场合。不能替用户补出没有说过的原因、时间或立场。

中文输入属于用户主动编辑内容；即使普通学习页未开启双语，也可以显示本人输入。额外中文讲解按双语／显式帮助设置显示，不让专项强制覆盖全站语言偏好。

## 2. 基础起步示例

以下为人为编写的教学示例，不是用户已经说过的话或模型结果。

中文：**我现在正在检查这个问题。**

先明确意思：我＝执行者；检查＝动作；这个问题＝对象；现在正在＝进行中。参考英文：

> I’m checking the issue now.

显示结构：**I｜am checking｜the issue｜now**。本次重点是“正在做”如何表达，解释 am 与 checking 在这个句子中的作用；the issue 作为当前问题整体理解，不展开一整章冠词和名词规则。

然后让用户自己改：

| 改变的意思 | 参考表达 | 按需学习的点 |
| --- | --- | --- |
| 我每天检查日志 | I check the logs every day. | 经常做的事；不沿用 am checking 表示日常习惯 |
| 我昨天检查了日志 | I checked the logs yesterday. | 明确过去时间；动作形式变化 |
| 我现在没有检查这个问题 | I’m not checking the issue now. | 当前句型的否定 |
| 你现在在检查这个问题吗？ | Are you checking the issue now? | 当前句型怎样提问 |

这些变式按进度逐个使用，不在第一课一次灌入全部时态。先让用户知道“意思变了，英文哪里需要变”，再逐步掌握形式；不把中文词序与英文单词进行逐字连线。

## 3. 专项的最小递进路径

| 顺序建议 | 解决的高频表达问题 | 返回的场景 |
| --- | --- | --- |
| 谁／什么＋状态或动作 | 我是谁、在做什么、需要什么；区分必要的 be 与动作动词 | 说明当前工作、点餐 |
| 否定与提问 | 我不能做、我不明白、你是不是这个意思 | 确认需求、请求帮助 |
| 时间与动作形式 | 正在做、经常做、明确过去、下一步计划，按需逐项引入 | 进度、约时间 |
| 连接简单意思 | 给原因、补一个例子、说一个简单看法 | 问题说明、个人观点 |

这是围绕起步任务的路径建议，不是已批准的完整英语语法范围。复杂从句、所有时态和学术写作不作为基础阶段的前置条件。

## 4. 交互建议

页面主要展示自己的句子与当前一步，结构说明和参考答案按需打开。支持“先给结构提示”“看一个例子”“显示参考表达”“自己再说／写一次”，避免输入中文后立即铺出一整段译文。

起步可用填少量关键位置；稍后撤去句子骨架，改用关键词或英文情境提示，最后在没有中文题干和完整参考句时回应。能抄写不等于能独立写，能读出译文不等于能自己说；反馈分别说明。

纠正先看是否保留原意、能否理解，再优先处理当前学习点。语法正确但不适合语境，与语法错误分开解释；允许多个自然答案，不能按参考句字符串一致性判错。用户决定是否采用候选改写，不能自动覆盖原稿或正式作品。

## 5. 怎样判断有帮助

建议观察：能否说明为什么这样组成句子；能否改变人物、时间或否定／疑问后正确表达；能否在另一高频任务里脱离完整译文说或写；隔一段时间是否仍能用。具体评分和间隔尚未确认。

欧洲委员会关于[多语言意义中介](https://www.coe.int/en/web/common-european-framework-reference-languages/mediation)的说明支持将已有语言资源用于理解和表达。本专项由此采用中文作起步支架；这不证明逐句中译英是学习听说读写的最快方法。专项必须回到英语听读、独立输出和真实互动，以实际使用效果调整提示强度。
