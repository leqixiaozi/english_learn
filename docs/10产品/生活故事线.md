# 生活故事线：从基本词句处理成人日常事务

## 定位与已确认边界

本站的故事课程分为**生活故事**和[工作故事](365场景故事线.md)。现有S001—S365完整保留为工作线，生活线另外编写、单独续学，不占用或重编号S卡。工作线中的客户出差、同事午餐等仍留在原剧情；生活线关心本人生活中的选择、约定与办事结果。两线可以共用已学表达和外部参考条目，但不复制同一剧情、课次、笔记或来源证据，也不要求互相解锁。

本页维护生活课程的**五章连续主故事＋一章按需事务**，以及首批**21张原创场景草案**；目录不是词汇表，21也不是用户确认的生活课程总数、已完成的英语课文或已选主视频数。用户从基本词句开始，优先能在现实生活中高频使用的短回应，再逐步增加条件、追问和书面确认。具体城市、住处、朋友、消费、健康和家庭事实都不能冒充本人经历；下列人物和事件只是可替换的教学设定。

## 故事怎样串联

建议以“在英语交流环境里安排自己的普通生活”为教学背景，不预设移民或长期海外定居。学习者有一个日程、一份购物清单、若干与朋友的消息及个人事务记录。Sam是持续出现的虚构朋友；Mira是L019与L020共用的**虚构家人**，教学时可替换成愿意交流的亲友，不映射本人真实家庭。邻居、店员和服务人员只在有关任务出现。每完成一件事，把**已确认的信息**沿用到下一课；等待回复的改约、送货或维修不写成已经办成。生活故事可以通过日常安排、餐饮、购物、社交和服务逐渐展开，不要求一周内发生全部意外。

## 生活主故事与按需事务目录

主故事围绕普通一周中持续使用的日程、周末约定和购物清单，按**先认识邻居并说清名字 → 约定 → 采购做饭 → 确认去处并赴约见面 → 在实际去的场所点单 → 联系亲友并回顾**推进。先用姓名、住处附近的简单短句开口，再要求商量时间地点；Sam仍是已认识的朋友，不需重新制造相识情节。起床、洗漱、下班和睡前安排作为同一人物生活的画面、听读输入或对话背景出现；没有交流目标时不各算一课。第六章的包裹、退换和报修是按需事务，跳过后主故事仍能从第一章走到第五章。表中编号是稳定的内容身份，**浏览顺序依下列故事链，不按L编号机械排序**；现有L001—L018不重编号，新补的正常事件使用L019—L021。

| 章 | 连续任务与本人的结果 | 主故事顺序及分支 | 从基本词句到更难的表达 |
| --- | --- | --- | --- |
| 1. 邻里相识与周末约定 | 先说清姓名与附近位置，再和Sam确认周末见面的时间、地点 | L002 → L001；L003仅在时间冲突时进入；早晚日程作剧情过渡，不编成孤立动作卡 | 我是／你是 → 附近有什么 → 我有空／没有空 → 何时何地；冲突时再学改约 |
| 2. 采购、晚餐与收拾 | 沿同一张清单买齐材料，做一顿简单饭并明确完成后的整理 | L004 → L005 → L021 → L019；L006仅在结账差异出现时进入 | 家里有／还缺 → 位置、数量、付款 → 谁做什么、现在完成了什么 |
| 3. 确认去处与赴约 | 沿第一章约定出门，告知预计到达并实际见面 | L008按需预订餐厅；L010 → L012是正常路径；L011只在方向不清时插入 | 去哪里／什么时候到 → 确认路线 → 抵达并互相找到 |
| 4. 外出点单与用餐 | 按实际去的场所完成一次订单；在餐厅就核菜单，在咖啡店就核饮品规格，不强制两处都去 | L008已确认餐厅时接L009；未订餐厅时L009（现场有位）或L007（咖啡店）二选一。确有两次不同购买才都做 | 我要这个 → 问清当前商品的内容或规格 → 复述最终选择与付款 |
| 5. 亲友联系与生活表达 | 用前几章确已发生的安排或选择与家人／朋友交换近况，再表达一个理由 | L020 → L018；L016、L017只在出现邀请或拒绝需求时进入 | 简短近况 → 一个选择和理由 → 回答追问、写短记录并尝试口述 |
| 6. 订单、包裹与居家服务（按需） | 本人确有购买、退换或设备服务需要时，核身份、时间与处理结果 | L013按需；L014只在商品不符时进入；L015只在确有报修时进入。**不阻塞第一至第五章** | 我的订单／预约 → 差异或现象 → 对方确认的下一步；未交付不写已完成 |

**时间线校验**：周初L002与邻居互报姓名、交流一处附近设施，随后L001与已认识的Sam约好周末见面；本周另一天L004—L019完成晚餐；临近周末如需餐厅则L008确认新地点并通知Sam，L010据最终地点选路，L012实际见面，L009或L007按实际场所完成一次点单；之后L020联系家人，L018只复述已经发生的选择。改约、找不到路、付款差异、退换与报修均不预设发生。若L001的地点已定且不改，则跳过L008；不会同时保存两个互相冲突的见面地点。

健康就诊、重大旅行、儿童照护、装修与复杂金融事务均可留作**本人实际需要时的条件支线或来源参考**，目前不占起步主目录。工作线的客户出差、项目会议、同事午餐仍只在工作故事中；生活线可以复用“确认时间”“请求帮助”等表达，但每次要有自己的生活对象和不同结果。L001—L018保留原编号和引用，新增L019—L021只是补足正常故事事件，不表示最终生活课总数已确定。

下表中的“常用”可按本人需要进入，“按需”是非必经的普通事务，“条件”只在出现相应问题时选择，均不设为解锁必修。每张卡均须在后续教材编写时补原创听读材料、本人说与写、对方追问及明确结果。编号L001起，与工作线S编号分开；编号用于稳定引用，学习顺序见上表。主视频栏暂不逐卡指定；每卡若有合适素材，最多嵌入一部经核内容和片段的主视频，其余作参考链接。没有合适视频便留空，原创文字和录音仍可承载课程。

| L001 约好一次周末见面 | Sam问你周末是否有空，需要约具体时间 | 说明可用时段 → 问对方想做什么 → 确认见面时间与地点 | 一条双方确认的见面安排 | 常用 |
| L002 认识附近的一位邻居 | 新邻居主动打招呼，你们还不知道怎样称呼彼此 | 互报名字 → 核对称呼与住处的大致位置 → 交流一项附近常用设施并道别 | 一个可正确称呼的生活联系人 | 常用 |
| L003 见面时间需要调整 | 原约定与一项真实安排冲突，Sam尚不知道 | 说明原时段不能到 → 提出或询问新时段 → 收到确认并更新消息 | 更新后的约定，未回复时标待确认 | 条件 |
| L004 确认晚餐需要买什么 | 你准备做一顿简单晚餐，家里还有部分食物 | 查看已有物品 → 说缺什么及需要多少 → 决定是否现在去买 | 只含缺项和数量的购物清单 | 常用 |
| L005 在店里找到清单上的物品 | 按L004的清单进店，需要核一件商品的位置或规格 | 说明要找的东西 → 听店员指出位置／规格 → 找到并确认这件商品，按同一清单选齐其余物品；缺货时才问替代 | 待结账的清单商品；缺货另记待替代，未补齐前不写材料齐备 | 常用 |
| L006 结账时核对价格或数量 | 收银记录与你拿的商品不一致 | 指出具体商品与差异 → 请店员核实 → 确认实际金额后付款或放弃 | 核对后的收据或尚未购买的决定 | 条件 |
| L007 在咖啡店完成一次点单 | L012碰面后选择在咖啡店坐一会儿；也可在本人另一次外出时使用，不要求先去咖啡店再去餐厅 | 说出饮品与一项规格 → 回答堂食／带走或缺货追问 → 复核订单并付款 | 本次实际点单，不替本人设定固定喜好 | 常用 |
| L008 预订与朋友吃饭的位置 | L001约好见面后Sam提议改去餐厅，尚未预订 | 先与Sam核人数和可改的时段 → 向餐厅询问并确认空位 → 把最终时间地点发给Sam并等其确认 | 餐厅与Sam均确认的见面时间、地点和人数；未答复时不覆盖L001的约定 | 按需 |
| L009 用餐时核对一项选择 | 菜单信息不足以让你决定吃什么 | 问一项菜品内容或份量 → 根据回答选择或换选 → 复述最终订单 | 自己确认的餐食选择 | 常用 |
| L010 为已约地点选交通路线 | 你需要按L001或L008的地点出门 | 说明出发地与目的地 → 核车次／站点或步行时间 → 告知Sam预计到达 | 与既有约定一致的路线和到达时间 | 常用 |
| L011 途中发现方向不确定 | 车站或路牌与预想不一致 | 说明当前地点和目的地 → 请对方指出下一站或出口 → 复述并实际走到正确位置 | 到达的站点或新的可执行路线 | 条件 |

| L013 收取一件已购买的包裹 | 送货人员需要核地址或可收件时间 | 核订单与地址 → 说明可接收的时间或方式 → 收到确认并检查实际交付 | 已收包裹或明确待送状态 | 按需 |
| L014 收到的商品与订单不符 | 包裹里的型号、颜色或数量与订单记录不同 | 对照订单说清差异 → 问退换或补发办法 → 记录商家同意的下一步 | 退换安排；未收到替换品前不写完成 | 条件 |
| L015 预约一次生活服务 | 一个居家设备或网络问题需要服务人员查看 | 描述可观察的现象 → 核可预约时段及地址 → 确认上门安排 | 预约已确认；故障是否修好待实际检查 | 条件 |
| L016 邀请朋友参加一项休闲活动 | 你看到一项近期可参加的活动，想问Sam是否有兴趣 | 简述活动与时间 → 听对方兴趣及限制 → 确认同行或各自安排 | 一项真实确认的休闲计划或明确拒绝 | 按需 |
| L017 礼貌拒绝并约另一次 | 收到邀请，但你已另有安排 | 感谢并说不能参加 → 简短说明相关限制 → 如愿意提出可行替代并核对 | 对方知道这次不参加及是否另约 | 按需 |
| L018 向朋友讲清一次生活选择 | Sam问上次的购物、餐厅或活动怎样 | 说发生了什么 → 说明一个喜欢或不喜欢的理由 → 回应追问并写两三句个人记录 | 可复述、可用于以后观点视频的本人生活表达 | 常用 |
| L019 完成一顿晚餐并确认收尾 | L021买回材料后，虚构家人Mira问晚餐安排并准备来吃；不预设本人实际同住或家庭状况 | 说明已有材料与开饭时间 → 与Mira商量谁准备一项食物或带一件东西 → 饭后确认用餐与收拾实际完成了什么 | 一次完成的晚餐和收尾记录；未完成的家务留待办 | 常用 |
| L020 与家人确认近况和通话安排 | Mira在另一日发来消息询问周末近况；不假定婚育、亲子或同住 | 用前几章已发生的一件事简短回应 → 问Mira近况与何时方便通话 → 收到确认或保留待回复状态 | 一条双方确认的联系安排及可复述的生活近况 | 常用 |
| L021 按清单完成普通结账 | L005选好清单物品后，收银员询问袋子与付款方式 | 复核商品数量 → 回答是否要袋子及付款方式 → 确认应付金额并完成付款，保留收据；有差异才转L006 | 已购买的材料和实际付款记录，供L019使用 | 常用 |

L003、L006、L011、L014、L015是条件分支；L008、L013、L016、L017是按需事务，不能为凑场景强迫用户经历全部冲突或额外邀约。L004／L005／L021／L019围绕同一张清单推进“确认缺项→找到→购买→做饭与收拾”；L006只在付款异常时插入。L001／L010／L012围绕同一次约定推进“定地点→选路→见面”；L003／L008改变约定时须先得到对方确认。L007／L009分别解决咖啡店饮品与餐厅正餐选择，**一次外出先按实际场所选一张**，只有真实经过两处才各做一次。L020／L018从已发生的事形成近况与观点；各卡的交流目标和结果不能只换几个词重复。

## 来源怎样服务于原创生活课

已核的成人生活素材并非空白，过去的缺口是它们主要被附在工作出差与参考目录中，未独立编成生活线。视频偏好现明确为**动画、固定人物、跨集事件连续**；可先参照[Jessica Dora分集及BBC《The Flatmates》候选的核查](10学习资料/系列课程目录.md#118-动画连续剧情优先同一人物和前后因果)，观察前一集的约定、物品和人物关系如何影响下一集。但Dora是年轻记者，《The Flatmates》较旧且部分材料属中级，本页仍需原创成人初级短句、符合本人真实目标的交流结果，不能把外部角色的经历变成本人经历。[课程规划的生活选材](课程与练习规划.md#生活故事独立选材与起步顺序)列出BBC Real Easy English午餐／周末／购物、British Council A1 Listening点餐／购物／预约／社交，以及已读Easy English动画片段，可在对应卡点补语言。另见[来源目录新增候选](10学习资料/系列课程目录.md#92a-a1-listening生活短来回本次新增候选)：BBC官方YouTube周末计划和Easy Languages街访购物视频目前只有发布页元数据，尚未完整核片。来源的讲稿、字幕、音频、视频及本站播放状态分别标注；参考事件不能自动成为本页角色的经历。

**优先取材对应（参考链接，不是主视频指派）**：[British Council *Starting Out* 第1集](https://learnenglish.britishcouncil.org/free-resources/general/video-series/starting-out/episode-01-they-meet)的姓名短句可先帮L002开口；[第3集](https://learnenglish.britishcouncil.org/free-resources/general/video-series/starting-out/episode-03-what-do-you-doing)实际经历邀请、比较活动、最后决定购物，可借L001的商量结构，不能把恋爱剧情移入Sam的普通朋友约定；[第4集](https://learnenglish.britishcouncil.org/free-resources/general/video-series/starting-out/episode-04-where-are-you)在商店不同楼层互报位置、追问后见到人，只在L011／L012需要定位时参照，不使每次见面都走错。三集均已核官方文字讲稿、练习及支持包入口，画面／音画和本站嵌入仍待核。British Council [A1购物听力](https://learnenglish.britishcouncil.org/free-resources/listening/a1/shopping-clothes)有问位置、尺寸、付款方式与袋子的完整短来回，可给L005／L021借语言结构，但原件是衣服，不能假称晚餐材料；[A1咖啡店听力](https://learnenglish.britishcouncil.org/free-resources/listening/a1/ordering-cafe)可给L007借规格、堂食或带走及结账追问，二者是音频加讲稿和练习，不列视频候选。

[BBC *Easy English Conversations* 2026四份官方练习](10学习资料/系列课程目录.md#119-生活卡的原版短句与练习对应本次核读)给L001的时刻确认、L020的真实日常频率、L018的周末回述与感受提供短写口说任务；练习PDF不是视频讲稿，L020也无需为了练频率虚构锻炼习惯。[VOA *Let's Learn English* 第35—36课](https://learningenglish.voanews.com/a/lets-learn-english-lesson-35-lets-make-dinner/3571922.html)核到购物单拿错后临时更改晚餐的跨集因果、页面视频、对话稿与口语／发音入口，可供L004—L019的“同一清单承接下一步”设计参考；那是戏剧情节，第二集荒诞的食材存放与早餐当晚餐都**不是**本站家务或食品处理示范，也不要求本人的正常采购出错。两集尚未指定为生活卡主视频或验证本站播放。

下一步编课时，从每张卡的交流结果选最贴合的一段输入，先写原创基础版本，再决定是否加入单一主视频。听、说、读、写仍围绕同一对象：听对方提问或选项，读日程／清单／订单，说自己的选择并回应追问，写下双方确认的结果。语法专题按表达意义独立学习；正在讨论的单词专题可用生活小故事练名词与抽象词，但不能代替本页办成具体事情的场景课。
