# 场景教学与专项训练

## 已确认的方向

以[产品总览](总览.md)为需求入口。用户明确：英语从基本词句开始；偏向场景教学＋专项训练；场景不重复；词汇、语法合理融入；单独设置中文表述到英文语法章节；包含听说读写。进一步收窄为干中学，不专门背词，不做宽泛主题大全，优先发生概率大、实用的事情。

“干中学”的已确认含义是：由助手带着推进具体事情，用连续人物、对象和结果学习表达。故事课程现已确认拆为**生活故事**与**工作故事**两条独立路线。**现有S001—S365整体保留为工作线，生活线另外编写**，不从旧表挪卡或重新分配365总量。工作线沿用既有365张卡的角色与成果依赖，求职阶段的本人旧项目与入职后的Relay分别记录；生活线独立组织日常事务，不以面试、Relay或出差解锁。

教材采集服务于编写者研究真实情境、可迁移表达和教学方法；**有限的外部素材不限定原创故事的选题、课数或推进**。助手后续按本人的成人生活与程序员工作体系，原创足量的故事、短对话、听读输入、说写练习和可观察结果；不能把找到多少原片当作能编多少课。外部视频主要供用户拓展相关内容，不承载原创主课的完整教学。每个场景至多嵌入 1 个贴合的主视频，其余为参考链接；没有合适原片也正常完成原创课。完整教材将在用户后续要求时编写；当前交付场景大纲和视频候选，不冒充已完成课文、音频或视频集成。

以下课表、排序和交互为建议，尚未选定技术栈或批准实施。“高频”是根据个人生活及程序员工作作出的优先级判断，没有用户使用记录或统计概率作为依据。

## 1. 学习方式与系列组织

**场景教学**：在生活或工作故事中跟进一件具体事情。首页直接继续所选路线的当前课，主体展示当前任务、实际问题和本人输入；已有成果及补充材料统一放页底默认折叠区，不展示引导性内容。角色扮演中的任务提问属于学习内容，页面不另设使用教学或提示横幅；每条路线的人物与已确认事实保持连续，不能每一轮重新设定。

**专项训练**：核心为[中文表述到英文语法](中文表述到英文语法.md)，也允许围绕当前任务出现的听不清、不会提问、句子说不完整等卡点做短练习。练完回到原任务。用户正讨论用高频词和抽象名词编简短故事的独立单词专题；课程形式、入口与练习尚未确认，不能把它写成已定必修或先实施单词打卡。听说读写不拆成四套课程。

用户已确认生活与工作是两条原创故事课程；工作线现有Relay大纲，生活线已有连续目录与首批场景草案，两线均需逐章编写实际教材。外部材料按来源与相关任务归类，**系列内的视频按原平台的发布顺序展示**；来源之间可标注建议起点和负荷，不能重排原片序列。专题可独立选看，不强制先完成故事课，也不因此新增必修或重复场景。场景教学与专项训练是学习方式，系列是内容组织，二者不互相替代。视频表达从已经能说的句子开始累积。页面布局、原创/参考身份和底部折叠规则统一见[产品展示原则](总览.md#61-已确认的首页与全站展示原则)。

**故事课程的目录与内容分工**：一级选“生活故事／工作故事”，两条路线各自续学；二级选生活的**五章连续主故事＋一章按需事务**或工作十二幕；三级才是有触发、交流和结果的场景卡。生活线先做邻里姓名短来回，再与朋友确认约定，随后采购做饭、赴约、外出用餐、联系亲友并回顾；订单、退换、报修独立按需浏览，故事顺序不按L编号机械排序，21张现有草案与分支见[生活故事线](生活故事线.md#生活主故事与按需事务目录)。工作十二幕按求职旧项目、技术面试、入职、Relay需求开发测试、出差现场、验收迭代和观点视频推进，S001—S365及每幕结果见[工作故事线](365场景故事线.md#2-十二幕与能力安排)。生活不复制Relay出差，工作中的同事午餐不迁为个人生活课；相同短表达可迁移，但各卡必须处理不同对象与结果。目录与现有草案已归位，最终生活卡数、具体课文和两条线的课时长度仍待编写验证。

每张原创卡建议按以下内容顺序编写：**承接上次已确认结果 → 当前要解决的问题 → 听／读一条故事角色给出的具体输入 → 本人说或写并处理追问 → 留下可复用的约定、清单、任务状态或观点**。四项能力都围绕这件事出现，但长短按任务调整；当前词与语法仅在需要表达时进入，不另布置背词关卡。基础阶段先用一两句完成来回，随后增加限制、变化和理由，最后用已做过的事写短观点并口述。主课的听读材料由原创教材提供，相关原片用于按需拓展同类交流；原剧人物和剧情不替换本站两条原创线，每卡最多一部经核主视频，其余为参考链接，找不到留空。该结构是后续写教材的内容规格，尚非已制作的音频、交互或学习成效。

另设“系列教材”入口，排在专项训练之后，按Easy English、VOA等原始课程／教材来源展示卡片，再进入其课次目录。专题学习按交流任务和内容主题查找外部参考，系列教材按来源查找；同一外部课次可同时归入多个交流专题和一个来源系列，指向**同一份内容、笔记、学习状态与来源证据**，不复制课文、视频或进度，也不因多次归类计为多课。分类变化不改变365场景编号和原创主课的事实线。[语法专题](语法专题.md)另设入口，按表达意义组织，不是生活／职场／技术场景专题的子类；其中的现实短故事只是练习语法的载体，课次与进度独立。场景与语法可按当前表达需要互链，但不互相解锁或重复计数。课次的全文、字幕、音视频、练习分别按已核证据展示，缺失项保持缺失；视频按原平台首次发布先后展示，课程中的非视频课次沿原作者课程顺序展示。发布时序未核时保留可核的集数／原列表顺序并标明待核，难度只作选看标签，不替代来源顺序。

## 2. 按发生概率和实用性选择场景

优先判断：本人是否经常遇到、是否近期会用、表达是否能迁移、是否适合当前基本词句水平。频率相近时优先能马上使用且学习负担小的任务；不以词汇难度、题目数量或资料丰富程度作为优先级。

工作线完整维护在[365场景故事线](365场景故事线.md)，按12幕推进：认识自己与求职 → 初面和旧项目 → 技术面试与录用 → 入职及日常联系 → 需求 → 开发与沟通 → 测试排查 → 出差准备与抵达 → 客户现场与生活 → 验收上线与交接 → 迭代和成长 → 英文观点视频。每项均列人物与触发、至少三个相互承接的交流环节、完成结果、适用频度和主片候选或待选状态。生活线独立维护在[生活故事线](生活故事线.md)，不在本页复制两套场景表。

串联对象建议为虚构的 Relay 工单协作系统，首版围绕创建工单、分配负责人和更新状态，随后通过现场反馈与交付逐步推进。项目、人物和新加坡出差地点均是编写建议，尚未采纳为真实经历；也不要求先开发真实软件。原来的六段任务看板示范保留为局部入门样例，不再作为整条课程的主线与编号依据。

365是工作线现有场景覆盖数量，不是365天课表或流利承诺。生活故事另有独立学习路径，不能只由工作与出差中的生活情节充数；故障、行程变动等条件场景按需要择用，不要求所有意外都在一次出差中发生。模拟事务走完与语言能力掌握分别判断，后者仍看独立表达证据。

编写时先确定本章需要形成的交流能力，再设计剧情和原创材料，不为追求场景数量堆入新词语法。各章须说明任务、先修能力、新增点、必要支架、听说读写活动和可观察成果。成人任务可以先完成一个短回应，不能因技术面试排在前面，就要求基本词句起步者直接完成复杂面试或听懂自然语速长片。

视频来源与选片状态统一见[视频参考库](10学习资料/视频参考库.md)。优先研究 Easy English 的具体情境对话，其他来源补充结构讲解及真实职场迁移；每场景最多一个主播放器，其他视频、文字稿和教材为参考链接，只有来源方允许下载时才提供下载入口。尚未选到合适主片的保持待选，不能拿无关合集补齐 365 个空位；有主视频也不设强制观看解锁。来源证据区分原作者正文已核、自动字幕全文已读、仅章节／目录和仍待精听；自动字幕新增核读没有自动改变逐场候选状态，无可靠时间则留空。配套练习的情节不能冒充视频内容，完整参考资料入口统一见[视频库的配套章节](10学习资料/视频参考库.md#7-完整单课脚本与既有试播证据)。

### 2.3 每幕的输入、本人输出与难度

起步先给一个具体问题和少量必要信息，原创对话用基本短句；外部原片较长时，只选完整的小事件，或者先用原创简化输入再回看原片。逐步从完整句提示撤到关键词，再到只有情境。不同阶段仍围绕成人任务，不用儿童故事替代基础语言。

每幕至少留下一个下一幕真正会用的成果：介绍卡、安排确认、任务卡、问题记录、预订确认或观点草稿。若只是看懂并跟读，记录为输入或模仿；能用自己的信息回应追问，才是独立表达。已做动作、当前状态和接下来安排先分成短句，不强求一次用复杂从句和全部完成时。

例如原片的“请求延期”只能提供沟通结构。Relay 中应明确哪条任务、原期限、剩余工作和影响，先说出“我需要更多时间”，再补原因、提出有依据的新安排，最后写下一句双方确认。不能从原片里经理说“下周”就直接替自己承诺完成日期。

具体教材参考及取舍见[教材编写参考](10学习资料/教材选编.md)，原先的局部方向样例见[项目故事示范草案](10学习资料/项目故事示范课.md)。外部人物不直接并入本站虚构故事，原站播放后仍由本人用自己的信息推进任务。

| 回顾结果并形成自己的英文观点 | BBC 40；VOA L1 37、L2 1—3；开发者复盘，SR10／23／27／34 | 听不同观察，读实际项目记录，说“我的判断＋一个理由／例子”，写短稿并回应反例；区分事实、推测与态度，不复制教材人物成绩 |

**从基本词句开始，成人任务保持完整但首次回应可以很短。** 比如同一求助先做到“我卡住了—你能看看吗—什么时候方便”，之后再补发生条件和已试办法。完成时、过去完成时、技术长句和多项任务取舍按实际需要后用；不会这些并不阻止先交流。每阶段保留一句自己的判断或选择，逐步累积第12幕的视频素材，不等到所有场景学完才开始表达。

一次场景仍按“尝试听懂请求→按需看短文／中文辅助→用本人信息说和写→只修当前卡点→回应新的追问”推进。下一场再次用到同一成果时撤掉部分提示；延后能否独立说清作为观察证据，不设机械题量、固定生词数或看满课程才解锁。跟读、看稿回答与独立口述分别记录。

原课程中的失败和误解也可作为输入：先预测问题、指出缺失信息，再由本人完成正确确认。例如 VOA L1 41 未问清增长目标、BBC 53 遗失留言，本站应分别要求澄清标准和保存交接记录；这不是照抄原角色的做法。具体中文句法进入[独立专项](中文表述到英文语法.md)，随后立刻回原任务。

### 2.5 用新核读材料调整教法，不增加必修范围

[79组任务机制](10学习资料/系列课程目录.md#7-提炼给-relay-的79组任务机制)服务于原有任务，起步从当前幕的24项核心候选中选一件推进，不要求全部先完成。BBC的68份完整讲稿、VOA的82课重点事件段落及开发者178段完整对话已完成文字筛选；VOA其他教学环节、练习及全部媒体仍未验收。教材品牌与A2／B1级别不能代替本人适配判断，不要求按原系列顺序学完。

**完整任务从短回应开始，随后增加信息和独立程度。** 例如S179先说“创建失败—报错是什么—请谁帮忙”，以后才补条件、已试办法与待验证原因。相同工单继续在S182补证、S196协商试点、S197复测、S300向真实用户确认；各自推进不同结果，不重复编成“报问题—对方说修好—谢谢”。保留本人专业经验，不因英语基础弱就重学编程入门。

听说读写围绕同一结果：听角色问题，读必要记录，用自己的信息回应并留下下一幕会使用的消息。先给短句或中文意图，随后改关键词，再回应一个新追问；跟读、看稿、独立表达分别记录，延后在另一任务再用以观察保持。反馈先核原意、理解和回应，再修当前影响交流的一项句法；复杂完成时和假设按需求后用。当前没有录音、识别或评分实现，文字答对不当口语已完成。

姓名、日期、座位等核对能力已会时，可串在一次预订任务里完成；只换姓名或句式不新增一课。S097解决日常午餐去处与时间，S254处理客户工作午餐与现场安排，结果不同。个人观点从每阶段的一句判断或选择开始累积，不等365张卡学完才开始视频表达。

**交流完成与事情做成分别判断。** 拒绝邀请、暂时不能解决或资源仍待批准，都可形成有效交流，但必须说明限制和下一步。S321／S322的反馈要有例子及可观察动作；答应看代码、少投诉或培训好评不能分别当修复、实际好用和独立掌握。面试引用本人旧项目，入职才开始Relay；同一预订、现场观察、软件验收和未来计划保持对象及时间连续。这些是后续教材的编写规则，尚无已验证的学习效果。

### 2.6 原创主课与参考专题的系列排序

用户确认的组织方向是**生活与工作两条原创故事＋参考专题系列**。课程浏览先呈两条原创故事及各自续学；来源卡可说明适合的起点及动画连续性。下方1—6行按**句子与任务难度**给编写者和学习者选来源、选片段用，来源目录的[动画连看优先级](10学习资料/系列课程目录.md#118-动画连续剧情优先同一人物和前后因果)用于发现连续剧情。**这两种研究排序都不作为视频列表显示顺序；系列及专题内同一来源的视频按原平台发布顺序展示。** 参考专题可按近期要办的事筛选，不是强制解锁；外部片不挤进365个场景，也不把看完一套视频当能力证明。

#### 生活故事：独立选材与起步顺序

生活线是与完整保留的Relay工作线并列的原创故事课程，不把它做成出差附录，也不把来源视频拼成同一人物的真实经历。按[生活主故事顺序](生活故事线.md#生活主故事与按需事务目录)先做L002姓名与附近位置的短来回，再在L001与已认识的Sam确认约定；随后用同一清单买菜做饭，继而赴约、用餐、联系家人并回顾。这样先用最短的自我介绍开口，再逐步增加时间、地点、选择和理由。改约、找不到路、付款差异、退换和服务问题只在触发时插入。L001—L021是当前完整场景草案的稳定编号，不是强制学习顺序，也不替本人设定家庭、婚育、健康或消费事实。下表只列编课输入，不表示已选定主片。

起步时也可按“一天的动作”串起同一份日程：起床与准备 → 早餐和当天安排 → 出门／居家做事 → 晚餐清单、采购和烹饪 → 整理与亲友沟通 → 明天的安排。这是生活线的**叙事顺序建议**，不把每个动作都拆成独立场景，也不要求用户真实经历全部家庭情节。[定向视频核查](10学习资料/系列课程目录.md#116-从起床到睡前家庭生活按真实动作补生活线)列出 BBC 初级句子课、Bob 真人两段演示及已核家庭短事件的用途和证据边界；先由本站写适合本人生活的短句和完整交流任务，视频只在确有对应片段时选为该卡唯一主片，其余作参考。

用户进一步确认视频优先**动画、固定人物、跨集事件连续**。因此生活故事先参照[Jessica 的 Dora 已核1—9集](10学习资料/系列课程目录.md#118-动画连续剧情优先同一人物和前后因果)的搬入、购物、探亲及个人安排，工作故事参照同系列面试、录用、入职以及BBC《English at Work》的长期职场因果；《The Flatmates》先列较难的生活连续剧候选，待完整目录与难度核实。**本站原创的生活与工作两条线仍分别推进**，不把Dora记者经历、BBC商贸故事或来源人物家庭条件写成本人事实。开始阶段由本站用基础短句和明确任务提供支架，视频仅取适合的完整事件或可核片段；看懂整套动画不作为开课前提。每张卡最多一部主视频，其他剧集与来源链接作为参考。

## 3. 场景去重与必要再用

主课按“沟通目的＋主要困难＋完成结果”核对是否重复。仅更换姓名、公司、地点、商品或数字，不能作为一节新的主场景；换到生活背景但仍只是同样的自我介绍，也属于变式，不充作新课。

用户进一步要求 365 项都必须是完整场景。每项应是一件能从触发推进到结果的交流事件，例如在初次见面中建立联系、在面试追问中讲清相关经历、与同事协商并落实交接。单独拼读姓名、换一个时态、挑选标题、给词标重音等属于场景内动作；只有把它们放回有问题、有回应和有结果的实际交流，才可以构成一张完整场景卡。完整场景不等于本轮已编好整篇英语对话、音频或题目。

同一人物、项目和物品持续出现是故事连续性，不算场景重复。是否为新场景看沟通任务是否推进；例如首次说清需求与演示时回应反馈，可以针对同一功能，但需要完成不同的事。

复习与变式明确标为复用已有能力，不计入新场景。语法、表达和常用词可以在不同任务里自然重现，例如站会和约时间都可能用到 work、today、tomorrow。用户可以自愿回练；不强制反复完成同一剧情来解锁新课。

识别、跟读、抄写与独立表达分别记录证据，不能只因看过答案或做对一道选择题就标为已掌握。建议用“在另一任务中脱离完整答案也能表达”核迁移，用延后再尝试核保持；具体检查频次不预设成固定打卡表。

## 4. 词汇、语法怎样融入

先明确要办的事，再展示够完成任务的短材料。只解释当前理解或表达所必需的词、搭配和句法；常用搭配结合完整意思使用，不拆成必须背完的孤立词表。

例如要表达“我正在检查这个问题”，学习 I’m checking the issue，理解 I’m＋动作的 -ing 形式如何表达正在进行，再替换为本人正在做的事。不会 issue 时提供当前语境中的解释；不因此跳转到一套词汇课。确实没理解的语法进入短专项，理解后立即用于当前任务。

是否增加新内容由实际理解和输出决定，不硬塞每课固定数量的生词、语法点。替代词只要意思和场景合适就可接受，不要求复刻唯一参考句。阶段目标是能办成事、说得明白，再逐步提高准确度。

### 4.1 中文到英文专项怎样嵌入主课

用户本轮要求把视频与教材对照所得的方法融入既有场景。完整[表达训练体系与S152示例](中文表述到英文语法.md#36-按意思组织的表达训练体系)维护在独立专项；[来源核读与不采纳内容](10学习资料/教材选编.md#6-中文到英文语法的来源核读与取舍)维护在教材入口。这里规定主课怎样调用，不复制一套语法教材。

主课先给当前实际问题或角色消息，让本人说／写；出现卡点时短暂进入专项，用本人中文澄清意思，尝试最短完整英文，按需解释一个区别，再听角色追问、写下结果并返回同一任务。初期中文是支架，后续逐渐改为英语情境与本人独立回应，不要求每次都先想中文。

田磊的中文讲解、张满胜的中文解释和剑桥例题是**参考与编课依据**。不将中文讲解视频自动指定为场景主片，不用它替代英文听读；每场仍最多一个合适主视频，其余进入参考。来源、结构说明、参考答案和反馈遵守[全站展示原则](总览.md#61-已确认的首页与全站展示原则)，放在页面最底部并默认折叠，按用户主动操作查看；不加流程导览、教学理念横幅或强制观看。

这是一套已按本次授权写入的课程设计，具体例句和支架强度仍待试教。后续以能否保留原意、理解对方、独立回应与延后再用调整；没有本人学习实测，不能写成已证实最快或已有自动反馈实现。

## 5. 听说读写放在同一件事里

| 能力 | 同一场景中的活动 | 起步阶段的反馈 |
| --- | --- | --- |
| 听 | 先听一句简短请求或回应，抓住关键意思；需要时再开文本或中文辅助 | 听懂了什么，卡在声音还是意思；看过文本不能记为独立听懂 |
| 说 | 先模仿必要短句，再换成自己的信息，并回应一个追问 | 是否把需要说的事说明白；跟读与独立表达分开 |
| 读 | 看短对话、任务卡、消息或菜单，找到完成任务需要的信息 | 是否理解关键信息，不要求逐词翻译 |
| 写 | 写出自己真实会发的一两句消息，或把准备说的话简短写下 | 是否保留原意、是否可理解，再处理影响表达的语法 |

四项在一个完整场景单元中都出现，但不要求每个短练习都做四遍同样内容，不机械四等分时长。口语录音回放、语音识别和自动反馈是不同能力：若尚未接入，不能把文字输入冒充口语训练完成。自动识别结果也不能单独证明发音正确。

建议场景顺序为：看清目标 → 短听读输入 → 试着说／写 → 只补当前卡点 → 再做一次自己的表达。允许跳过已经会的示范，答案与中文辅助按需揭示；中文显示遵守产品双语规则。

每次开始先简短回顾上一幕的真实选择，结束时明确本次让项目发生了什么变化，再进入下一幕。主要输入应是与当前人物和剧情一致的原创对话、消息、图文与听力材料；参考来源用于帮助编写，不将不同教材人物拼接成同一故事。原创听力的录制或生成方式仍待确定，文字稿不能冒充已有音频。

## 6. 科学依据及适用限度

欧洲委员会的[行动导向教学说明](https://www.coe.int/en/web/common-european-framework-reference-languages/the-action-oriented-approach)提出用跨多课的真实统一情境，逐步推进到最终任务或作品，并结合接收、产出、互动与意义中介。本方案据此用贯穿项目组织不同场景，让听说读写共同服务于最后的项目介绍和个人表达；这并不证明此方案对本人必然最快。

IES 的[学习组织实践指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)支持分散学习、主动提取及示范与独立尝试交替。这里将其用于任务中再次使用表达、延后尝试和逐步撤去提示；该指南覆盖一般学习研究，不能据此宣称某个英语界面、复习间隔或中文转换方法必然最快。

以上是设计依据，不是本站学习效果实验结果。是否更适合本人，应看真实任务完成、离开提示后的表达和延后保持情况，不以打卡天数或单词数替代。
