# 项目故事示范草案：接手一个小团队任务看板

## 范围与来源

本页保留原先任务看板的局部入门草案，用来检查“带着跟进一个项目”的方式；不是最新[365 场景故事线](../365场景故事线.md)的第一幕，人物与项目也不直接混入新主线。项目、角色与对话由助手编写，题材尚未采纳，也不是已编成的正式教材。完整原创教材等待用户后续要求。本轮没有编写网站或项目代码，也没有生成这份原创对话的音频。

编写者参考过[British Council A1：Meeting new people](https://learnenglish.britishcouncil.org/free-resources/speaking/a1/meeting-new-people)的办公室初次见面情境、文字稿和活动入口。该来源不作为本幕必修视频；后续正式教材应使用与本站人物和剧情一致的原创内容。

## 1. 同一件事，从这里开始

你是一名开发者。项目对接人 Alex 所在的小团队把任务散落在聊天消息里，容易忘记谁在做什么，希望有一个简单看板。你将跟进沟通、确认需求、处理问题、演示交付，最后把这段经历讲给朋友听。

当前只是模拟接手，不需要写出程序。项目后续范围暂定添加任务、查看状态、标记完成，不引入登录、支付或复杂技术选型。

本幕只完成两件相连的事：让 Alex 知道你的身份；理解他需要一个简单任务看板。结束时留下一张项目卡，第二幕沿用它来约需求讨论。

## 2. 原创听力环节，待后续编写

正式教材应围绕本幕人物编写简短听力脚本，让用户听出谁在介绍身份、对方需要什么。外部资源用于研究难度与活动形式，不要求用户先打开外部课程才能继续故事。

当前只有下面的文字草案，没有原创音频，不能声称已完成听力教材。后续需要按最终脚本确定录制或生成方式；看文字理解与独立听懂仍须区分。

## 3. 进入自己的项目

下面是原创模拟对话。先理解发生的事，不要求一次记住全部句子。

> Alex: Hi. I’m Alex. We need a task board.
>
> You: Hi. I’m [your name]. I’m a developer.
>
> Alex: We need a simple board.
>
> You: OK. I can help.

这里的 task board 就是这次要做的具体对象，用一张示意任务卡理解即可，不另开 task、board 的背词作业。I can help 可以先作为回应对方的整句使用，等实际需要表达能力或请求帮助时再深入。

## 4. 用你本来就想说的中文学一句语法

真实表达意图：**我是一名程序员。**

先尝试自己写或说，再按需要看支架：

> I am a developer.

这次只看 **I｜am｜a developer**：谁是我，用 am 连接身份，a developer 整体表示一名开发者。I’m 是 I am 的缩写。先把身份说清楚，不把所有 be 变化和冠词规则一次教完。

迁移一步：现在不是重复介绍自己，而是理解 Alex 的需求。

> We need a task board.

中文意思是“我们需要一个任务看板”。这里 need 已经承担“需要”这个动作，不能机械在每个句子里都加 am。两句分别处理身份和需求，结构因意思而不同。需要更细提示时进入[中文语法专项](../中文表述到英文语法.md)，随后回到当前对话。

## 5. 听说读写都为这一幕服务

| 活动 | 这次具体做什么 | 怎样核效果 |
| --- | --- | --- |
| 听 | 正式课程从原创故事音频听出身份与需求；当前音频待制作 | 分清独立听懂和看稿后理解，当前未验收 |
| 读 | 读下面这张原创项目卡，找出要做的东西 | 能指出它是任务看板，而非无关项目 |
| 写 | 用自己的名字和身份给 Alex 留两句介绍，不要求与样例完全一致 | 原意正确、可以理解；按需修正当前结构 |
| 说 | 隐藏完整介绍，回应一句身份确认，再表示愿意帮助 | 能自己表达，不只是照读译文；尚未实际录音或评价 |

项目卡：

| 项目要素 | 当前故事中的值 |
| --- | --- |
| Project | Team task board |
| Contact | Alex |
| Goal | See the team’s tasks |
| Next step | Arrange a short meeting |

这张卡是当前教学样例，不是替真实用户确认的需求。用户后续选定自己的对象、名字或目标时，用本人确认值更新，后续章节继续沿用，不让故事自动改口。

## 6. 收尾与下一幕

本幕结束应留下本人介绍，以及确认过的项目目标。只会读出样例时继续给必要提示，不把“看过”标为“已掌握”；表达能被理解后即可进入下一步，不要求背完一页单词。

下一幕使用同一个 Alex 和同一个看板，约定讨论的时间地点，再自然进入碰面与生活交流。前一幕保存的介绍不重新布置为一节“换个名字的自我介绍课”。后续各幕的需求、状态、问题说明和交接消息，最终成为本人项目介绍及观点视频稿的材料。
